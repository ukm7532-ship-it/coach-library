# coach-library

Lewin 教練的運動教材總庫｜復健訓練、動作教學與觀念圖解，給學員與長輩的互動式學習網頁。

## 結構

```
index.html            選單首頁（依部位分類、可搜尋）
bunion-rehab/         拇外翻康復訓練指南
deadlift-patterns/    硬舉動作模式比較
```

## 新增一份教材

1. 建一個新資料夾（英文小寫加連字號，例如 `knee-squat-cues/`），把教材網頁命名為 `index.html` 放進去。
2. 打開首頁的 `index.html`，在 `MATERIALS` 清單加一筆：標題、簡介、部位、類型、資料夾路徑、搜尋關鍵字。
3. 部位要是 `PARTS` 裡的其中一個（足踝、膝、髖與腰背、肩），要新增部位就加進 `PARTS`。
