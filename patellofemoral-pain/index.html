髕骨痛與髕骨軌道

膝蓋前側痛、有聲音，怎麼看

搞懂聲響 + 看懂髕骨的拔河 + 練大腿與臀部、調整下蹲
聲響 髕骨的拔河 大腿內轉 螺旋回返 放鬆的定位 強化 下蹲模式 自我檢查與練習
01 — 軟骨與聲響

膝蓋有聲音，不一定是壞事

髕骨（膝蓋前面那塊可以推動的圓形骨頭）的背面有一層關節軟骨（包在骨頭表面、光滑有彈性的組織）。 軟骨本身沒有神經，所以單純「卡啦卡啦」的聲音，常常不痛也不代表正在受傷。很多膝蓋完全健康的人，蹲下時也會有聲音。

比較不用擔心

  • 有聲音，但不痛
  • 不會腫、不會卡住
  • 聲音很久都差不多，沒有越來越嚴重

建議找人評估

  • 聲音伴隨疼痛，或痛越來越頻繁
  • 膝蓋腫起來、發熱
  • 膝蓋突然卡住、伸不直，或突然軟腳
  • 跌倒、扭到之後才開始有聲音
重點：軟骨不怕「磨」，比較怕的是兩件事：髕骨走的路線長期偏一邊，以及髕骨承受的壓力太大、加得太快。後面的內容都圍繞這兩件事。
02 — 髕骨的拔河

誰把髕骨往內拉，誰往外拉

髕骨在大腿骨前面的一條溝槽（滑車溝，像火車軌道）裡上下滑動。左右兩邊各有組織在拉它，平衡的時候髕骨就走在軌道中間。

往內拉
股內側斜肌（VMO） 大腿前側靠內、膝蓋上方那一顆
股四頭肌的一部分，是往內拉的主要肌肉，會出力、會累，可以訓練。
髕股內側韌帶（MPFL） 髕骨內側連到大腿骨的韌帶
膝蓋接近伸直時，它是拉住髕骨不往外跑的主力。韌帶不會因為訓練變強，但需要肌肉幫忙分擔。
往外拉
股外側肌 大腿外側最大塊的肌肉
股四頭肌裡最大的一塊，力量比內側大，天生就有把髕骨往外帶的傾向。
外側支持帶 髕骨外側的一片筋膜
連著髕骨外側，太緊時會把髕骨往外拉、往外傾。
髂脛束（ITB） 大腿外側從髖到膝、很硬的一條筋膜
有纖維連到外側支持帶，所以也間接影響髕骨。
還有一個常被忽略的穩定來源：骨頭形狀。膝蓋彎超過大約 30°，髕骨會「卡進」溝槽深處，靠溝槽的形狀就很穩。所以髕骨最容易往外偏的角度，是接近伸直到微彎的那一段。
03 — 大腿往內轉

髕骨沒有跑，是大腿在它底下轉

下蹲、下樓梯、落地時，如果膝蓋往內夾（動態膝外翻，膝蓋往身體中線倒），常常是大腿骨往內轉了。 髕骨被肌肉和肌腱拉著不太跟著轉，結果就是：軌道往內移，髕骨「相對」跑到軌道外側，外側那半邊的壓力變大。

圖解為簡化示意，角度刻意放大以便看清楚。真實情況還會受腳掌、骨盆、軀幹姿勢影響，也不是每個膝蓋往內夾的人都會痛。

為什麼大腿會往內轉？

  • 臀部肌力或控制不足：臀中肌（屁股外上方，負責把大腿往外撐）、臀大肌負責拉住大腿不往內倒。研究發現髕骨痛的人常有髖部肌力較弱的情況，但是先弱才痛、還是痛了才弱，目前還說不準。
  • 疲勞：練到後段、走遠路之後比較明顯。
  • 腳掌塌陷：足弓往下塌時，小腿跟著往內轉，膝蓋也會被帶著往內。

網路上常見、但講太滿的說法

  • 「骨盆前傾 → 臀中肌沒力 → 外側收緊 → 髕骨歪」：每一步都有可能，但這條連鎖目前沒有足夠證據串起來，不是每個人都這樣。
  • 「某一條肌肉是矯正骨盆前傾最重要的」：骨盆姿勢受很多因素影響，很難歸給單一肌肉。
04 — 補充小知識

螺旋回返機制是什麼？

Screw-home mechanism

膝蓋快要完全伸直的最後大約 20–30°，小腿骨（脛骨）和大腿骨之間會自動轉一點點，像把螺絲最後一圈鎖緊，讓膝蓋站直時比較穩、比較省力。 站著的時候，是大腿骨在小腿骨上往內轉一點；坐著踢腿的時候，則是小腿骨往外轉一點。 要彎膝蓋時，膝蓋後方一條叫膕肌（膝窩深層的小肌肉）的肌肉會先把這把鎖「解開」。

和髕骨痛的關係：這是每個人都有的正常機制，不是造成髕骨往外偏的原因。和髕骨軌道比較有關的，是上一節講的「動作中大腿往內轉、膝蓋往內夾」。兩件事都和「轉」有關，很容易被混在一起講。

05 — 放鬆的定位

放鬆能讓動作好做，但不會把髕骨「拉正」

髂脛束是很硬、很緻密的筋膜，用滾筒滾它，幾乎不會讓它變長，直接壓在上面滾通常又很痛。 比較合理的做法，是放鬆和它相連、或在大腿外側的肌肉，目的是暫時降低緊繃感，讓接下來的訓練比較好做。

闊筋膜張肌 TFL

在褲子口袋外側、髖骨前方的一小塊，往下接到髂脛束。

趴姿或側趴，球放在褲子口袋外側，小範圍滾或停留。

股外側肌

大腿外側、偏前面的大塊肌肉，是把髕骨往外帶的肌肉之一。

側趴或半側趴，滾大腿外側偏前方的肉，避開膝蓋旁的骨頭。

股二頭肌

大腿後側靠外的肌肉（膕繩肌的一條），下端在膝蓋外後方。

坐姿，球放在大腿後側偏外，用手撐地調整重量。

放鬆原則：每個位置 30–60 秒，壓到「有感但能放鬆呼吸」就好，不要滾到瘀青、不要直接在膝蓋旁的骨頭上壓。 有些影片也會放鬆脛骨前肌（小腿前外側），但它跟髂脛束、髕骨的關係比較間接，本教材不列入。
06 — 強化

練整條大腿，加上臀部

常聽到「專練內側頭（VMO）」。實際上，目前研究不太支持能把 VMO 單獨挑出來練； 比較有共識的做法是整體股四頭肌＋臀部（髖外展、髖外轉）一起強化。練習時仍可以「看著內側頭用力」當提示，幫助大腿前面整體出力。

股四頭肌（含內側頭）

負責伸直膝蓋、下樓梯和蹲下時踩煞車。膝蓋腫脹或疼痛後，大腿前面常常會「出力出不來」，內側頭變小、變軟會特別明顯，所以早期先把出力找回來很重要。

臀中肌、臀大肌

把大腿拉住、不讓膝蓋往內夾，下蹲時也能分擔膝蓋的負擔。髖和膝一起練，比只練膝蓋更常被建議。

練習放哪裡？具體動作放在第 08 段「入門練習」。
07 — 下蹲模式

膝蓋先動，還是臀部先動？

蹲下時如果膝蓋先往前衝、上半身挺直，膝蓋要出比較多力，髕骨被壓在溝槽裡的力量也比較大。 改成臀部先往後、上半身自然前傾，一部分負擔會分給髖關節和臀部。兩種都不是「錯」，但髕骨正在痛的時候，臀部先動通常比較舒服。

膝蓋先動膝蓋往前多、上身直
臀部先動臀部往後、上身前傾
膝蓋先動
臀部先動
髕骨壓力相對大小（示意，用膝蓋到上半身重心的水平距離估算）

示意模型，只比較兩種模式的相對差異，不代表實際受力數值。

08 — 自我檢查與入門練習

先看看自己，再開始練

這些檢查只是幫你「觀察」，不是診斷。看到明顯不對稱或有疑問，可以錄影帶去給教練或醫療人員看。

自我檢查

  1. 側面照鏡子下蹲

    側身對著鏡子，慢慢蹲到椅子高度做 2 下。看看一開始是膝蓋先往前，還是臀部先往後。膝蓋先動、腳跟快離地，就是上面圖解的「膝蓋先動」。

  2. 正面看膝蓋有沒有往內夾

    面對鏡子或請家人錄影，做雙腳半蹲，再做單腳小幅度半蹲（扶著牆）或下一階樓梯：

    • 膝蓋有沒有往大腳趾內側、往身體中線倒？
    • 單腳時，另一側骨盆有沒有往下掉？
    • 左右兩腳看起來一樣嗎？

  3. 聲響記錄

    有聲音時，同時問自己：痛不痛？之後會不會腫？只有聲音、不痛不腫，通常先觀察就好。

  4. 生活問句

    最近這些事會讓膝蓋前側痛嗎？

    • 下樓梯（通常比上樓痛）、下坡
    • 久坐後站起來（例如看完電影）
    • 蹲下撿東西、跪地
    • 跑步、跳躍

入門練習

DRILL 01

大腿前側收緊 quad set

「膝蓋窩往下壓毛巾，看大腿內側那一顆鼓起來」
  1. 坐著或躺著，腳伸直，膝蓋下面墊一條捲起來的毛巾。
  2. 膝蓋窩往下壓毛巾，大腿前面用力收緊，停 5 秒。
  3. 放鬆 3 秒，再來一次。
參考：10 下為一組，做 2–3 組。
常見錯誤：憋氣、用力抬屁股或夾屁股代替大腿出力、腳尖用力勾到抽筋。
長輩版：坐在椅子上做就可以，手可以放在大腿內側上方，摸摸看有沒有變硬。
DRILL 02

側躺蚌殼式 clamshell

「膝蓋像蚌殼打開，骨盆不往後倒」
  1. 側躺，膝蓋彎約 90°，兩腳腳跟併攏，頭枕在手臂上。
  2. 腳跟保持貼在一起，上面那腳的膝蓋往上打開，停 1–2 秒。
  3. 慢慢放回來。
參考：10–15 下，2–3 組。屁股外上方有痠感是正常的。
常見錯誤：上半身和骨盆跟著往後翻、打開太快、腰往前拱。
長輩版：背靠牆側躺，比較不會往後倒；打開幅度小一點沒關係。
DRILL 03

臀部找椅子的坐站練習

「臀部往後找椅子，膝蓋對準第二根腳趾」
  1. 站在椅子前，腳與肩同寬，腳掌（特別是大腳趾根部）踩穩。
  2. 臀部先往後，上半身自然往前傾，慢慢坐到椅子上（輕碰就好）。
  3. 腳踩地、臀部出力站起來。可以在膝蓋上方套彈力帶，提醒膝蓋不往內夾。
參考：8–10 下，2–3 組。
常見錯誤：膝蓋先往前衝、膝蓋往內夾、重心跑到腳尖或腳跟翹起、一屁股跌坐下去。
長輩版：椅子高一點、前面放一張穩的桌子可以扶；先求慢慢坐下，再求站起來不用手撐。

疼痛原則

用 0–10 分評估練習時膝蓋的不舒服（0 是完全不痛，10 是無法忍受）：

0–3 分：可以繼續超過 3 分：縮小蹲的深度、放慢、減少次數；調整後仍超過就先停

可以繼續的條件：練習時不超過 3 分，而且隔天沒有比較痛、沒有腫。隔天變更痛，下次就減量。

出現以下情況，請先就醫評估，不要自己硬練：

膝蓋明顯腫脹、發熱膝蓋卡住伸不直突然軟腳跌倒或扭傷後的疼痛夜間痛醒
總結一句話

膝蓋有聲音不痛不腫通常不用緊張；髕骨比較怕的是走偏和壓力太大。練習重點是大腿前側＋臀部一起練、下蹲時臀部先往後，放鬆只是幫忙讓動作好做。
